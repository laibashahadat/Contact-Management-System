# 📱 Contact Management System

A simple **Contact Management System** built with Python. This project allows users to store, search, update, and delete contact information through a simple interface.

## ✨ Features

- ➕ Add new contacts
- 📋 View saved contacts
- 🔍 Search contacts
- ✏️ Update contact information
- 🗑️ Delete contacts
- 🐍 Built with Python

## 🛠️ Technologies Used

- Python

## ▶️ How to Run

1. Make sure Python is installed on your computer.
2. Clone this repository:

```bash
git clone https://github.com/laibashahadat/Contact-Management-System.git
```

3. Open the project folder.
4. Run the Python file:

```bash
python "Project 4 . 📱 contact Management system.py"
```

## 🎯 Purpose

This project was created to practice Python programming concepts such as dictionaries, lists, functions, loops, conditional statements, and user input.
